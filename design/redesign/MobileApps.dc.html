Vestigra

PERSONAL PROJECT ANDROID · NATIVE

Find any name, number or code inside your own photos — without a single image leaving the phone.

Everything happens on the device: text recognition, the search index and the highlight geometry all live in the app's private storage. Indexing only runs while the app is open, and only after the user says yes.

WHAT I BUILT

  • A MediaStore gallery that survives permission changes, deletions and moved files.
  • An FTS search index over recognised text: order-independent tokens, prefix matches, normalised digits.
  • Word-position geometry so matches can be outlined on thumbnails and inside the photo.
  • Read-aloud, translation and a crop editor that always saves a copy, never the original.

RioPool

PERSONAL PROJECT ANDROID · iOS · WEB

Water quality monitoring for swimming pools: sensors report in, the dashboard reacts in real time.

A client opens the app and sees every prototype they own, whether it is reporting, falling behind or offline — with the readings behind each one, live and historical.

WHAT I BUILT

  • A layered Flutter client — presentation, application, domain, data — shared across four platforms.
  • Token auth with refresh, plus REST history and a WebSocket channel that resyncs after a drop.
  • A dashboard of metric tiles and charts, with typed error and empty states instead of blank screens.
  • Semantic status colours measured for contrast in both themes, always paired with an icon and a label.
